Working Memory Snapshot App State Mockups

Static design reference for the local-first macOS app. Screens use the supplied visual direction while preserving the current data model, SwiftUI route state, SQLite repositories, observation boundaries, and LM Studio local API contracts.

Implementation note These mockups do not add runtime dependencies. The production app remains native SwiftUI with SQLite, Keychain, and LM Studio local HTTP only.

Entry
