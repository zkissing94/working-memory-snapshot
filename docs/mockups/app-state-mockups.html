Working Memory Snapshot Two Column App State Mockups

Static design reference for the local-first macOS app. These screens use a persistent project sidebar plus one workspace column, while preserving Pomodoro blocks, manual increments, local evidence boundaries, and LM Studio dependency states.

Scope This file is a static mockup artifact. It does not change SwiftUI source, SQLite schema, repositories, observation, or LM Studio API behavior.
