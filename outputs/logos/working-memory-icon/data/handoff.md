# Working Memory Icon Exploration Handoff

Anchor: A local-first macOS utility that preserves the thread of thought so founder/coders can resume deep work quickly.

Final owner: macOS icon production

## Selected Logo Direction

- **Thread Through Snapshot** — A single thread passes behind a snapshot boundary and returns in front, expressing captured context becoming resumed work.

## Preserve

- Indigo and violet brand heritage.
- One bold silhouette.
- White snapshot frame and periwinkle thread.
- Rear thread → frame → front thread layer order.
- Clear rendering at 16–40 pixels.

## Avoid

- Brain, circuit, timer, document, cloud, chat, sparkle, and literal AI imagery.
- Letterform-first marks.
- Baked masks, bevels, shadows, or glows in vector source artwork.
- Close derivations of supplied reference icons.

## Rejected Directions

- Folded-W Memory Thread — materially close to several live blue-gradient app icons using a white folded W ribbon.
- Capture / Resume Loop — too close to generic sync marks.
- Interlocking Continuity Links — reads as collaboration or linking.
- Memory Bridge — reads as a generic wave.
- Nested Thread — drifts toward chat, email, and at-sign imagery.

## Production Result

- The deterministic foreground was rebuilt as three flat SVG layers over a full-bleed gradient background.
- `WorkingMemorySnapshot/AppIcon.icon` carries the Default, Dark, and Mono treatments.
- Xcode compiles the layered source into the `AppIcon` fallback for the macOS 14 deployment target.
- The flattened 512/1024 rendition supplies the existing 40-point sidebar tile.
